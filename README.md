# Keep Vault MCK

Offline-first note and prompt organization by MCK AI Studio.

## Project status

Development is in progress. This public repository currently provides project information; it does not provide a verified installable application or browser extension.

## Project goals

- Organize notes and reusable prompts in one place.
- Prioritize offline use and clear organization.
- Make the interface approachable for beginners.

These are development goals, not claims that the features have been released.

## Getting started

There is no verified installation procedure in this repository yet. Do not install unofficial downloads claiming to be Keep Vault MCK.

## Feedback

If GitHub Issues are available, use the [Issues page](https://github.com/mckaistudio/Keep-Vault-MCK/issues) to suggest improvements or report documentation problems.

For a useful suggestion, describe what you want to organize, the problem you encounter, and the expected result. Do not include private notes, credentials, personal screenshots or sensitive account information.

## Privacy and safety

Do not store passwords or recovery keys in early builds. Offline-first is a design goal and does not, by itself, establish encryption or security guarantees.
