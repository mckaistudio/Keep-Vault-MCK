# Keep Vault MCK — Phase 5: Google Keep import, duplicate quarantine, backup

Implement an offline-first Google Keep Takeout JSON importer and a Keep Vault JSON backup/export system without requiring a paid API or network calls. Preserve all existing Phase 1–4 functionality and data. Read Google Keep textContent, listContent checkboxes, labels and titles, review candidates before import, detect duplicate title/body pairs and quarantine duplicates (skip them without modifying existing notes), and assign fresh category @CODEs atomically through IndexedDB. Import only after user confirmation. Reject malformed files, cap file size and count, and report skipped files clearly. Support re-import of Keep Vault backups without overwriting notes. Do not falsely claim ZIP/attachment support; these are later enhancements. Explain that exported backups are unencrypted and must be stored privately. Provide tests for parsing, duplicates, backup round trips, validation, and regressions. Run npm test and npm run build and real Brave tests; report what actually passed. Keep the prompt independent from application code and do not merge main without explicit approval.
