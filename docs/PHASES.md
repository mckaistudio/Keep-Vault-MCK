# Phase boundaries

## Phase 1 — Foundation (implemented)

- TypeScript, React, Vite, and IndexedDB persistence through Dexie.
- UUID notes and transactionally allocated, unique `@000001`-style codes.
- Exact, title, content, and all-field local search.
- Real create, edit, save, view, and copy interactions.
- Responsive matte/gold UI, light/dark/system appearance, lite surfaces, and
  reduced-motion support.
- Keyboard-operable native controls, visible focus, and status/error announcements.
- README, architecture, security, phase, and evidence-based status documentation.
- ESLint, unit tests, and GitHub Actions CI.

## Not included in Phase 1

Accounts, server APIs, sync, remote backup, sharing, import/export, encryption
beyond browser storage protections, external AI, analytics, and native
applications are not implemented. Do not treat UI-only placeholders as completed
features; Phase 1 has no controls for these deferred capabilities.

## Open governance decision

The public repository has no license. Selecting a license is a maintainer
decision; this implementation does not add one.
