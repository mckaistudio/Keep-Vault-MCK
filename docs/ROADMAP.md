# Keep Vault MCK — Ten-phase roadmap

1. **Foundation:** responsive Liquid Glass UI, notes CRUD without deletion, IndexedDB, @CODE, search, theme, basic build checks.
2. **Organization:** tags, folders, pinned notes, inbox, history, exact-code search, index cheat sheet, quarantine preview.
3. **Prompt intelligence:** local audit, templates, comparison, variables, opt-in AI providers, versioning.
4. **Workflows:** linked prompts, reusable variables, approval-aware execution and progress.
5. **Google Keep import:** Takeout ZIP/JSON/HTML parsing, conflict previews, duplicates, reversible quarantine.
6. **Security and backups:** encrypted vault, secure ZIP backup and verified restore.
7. **Browser extension:** Brave/Chrome capture, Google Keep assistance with fallbacks, keyboard shortcuts.
8. **Mobile PWA:** installable offline experience, accessible touch UI, manual device transfer.
9. **Optional sync:** consent-driven secure cross-device architecture and conflict handling.
10. **Release:** browser compatibility, performance, security, accessibility, documentation, packaging.

Each phase needs implementation, test evidence, a phase-specific prompt, and an isolated GitHub checkpoint. Do not merge to main automatically.
