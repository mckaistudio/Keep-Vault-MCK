# Keep Vault MCK — 10 phases

1. Foundation: notes, IndexedDB, @CODE, search, responsive themes.
2. Organization: collections, tags, inbox, history, index.
3. Prompt intelligence: auditing, templates, versioning.
4. Workflows: prompt chains, approvals, progress.
5. Google Keep Takeout import, duplicate handling and quarantine.
6. Encryption, backups and verified recovery.
7. Brave/Chrome extension and Keep assistance.
8. Mobile offline PWA and manual transfer.
9. Optional secure cross-device sync.
10. Security, QA, accessibility and release.

Only Phase 1 is authorized now. Each phase gets a separate prompt folder and test evidence.
